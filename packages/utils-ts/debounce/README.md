# debounce

Откладывает вызов функции до паузы в `wait` мс после последнего вызова. Типичные случаи: поиск при вводе, сохранение черновика, пересчёт после `resize`.

```ts
import { debounce } from '@yellowweb/utils-ts';

const search = debounce((q: string) => api.search(q), 300);
search('re');
search('react'); // выполнится один раз, с 'react'

search.flush(); // выполнить отложенный вызов сейчас (например, при уходе со страницы)
search.cancel(); // отбросить (например, при размонтировании)
```

## Опции

| Опция      | По умолчанию | Смысл                                                                            |
| ---------- | ------------ | -------------------------------------------------------------------------------- |
| `leading`  | `false`      | вызвать сразу по первому вызову серии                                            |
| `trailing` | `true`       | вызвать после паузы с последними аргументами                                     |
| `maxWait`  | —            | верхняя граница откладывания: при непрерывном потоке вызовов fn всё же сработает |

## Почему так

- **Без зависимостей** — пакет остаётся чистым, нет лишнего кода в бандле.
- **`maxWait`** защищает от «вечного» откладывания и позволяет выразить `throttle` через ту же логику.
- **Время по `Date.now()`**, а не только по таймерам: в фоновых вкладках таймеры опаздывают, а решение «пора вызывать» остаётся верным.
- **Ошибки в параметрах — сразу при создании** (`RangeError`/`TypeError`), а не «тихо не работает».

## Ограничения

- Возвращаемое значение — результат **последнего выполненного** вызова (до первого выполнения — `undefined`).
- Для async-функций результат — промис последнего выполненного вызова; отменённые вызовы промис не создают.
